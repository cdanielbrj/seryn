# Version 0.4.0 Lumen integration validation

Validation ran on November 26, 2026, on Docker Desktop for macOS arm64. Build and test runtimes ran in containers, backend integration tests used temporary SQLite databases, and the shared development installation retained its existing persistent volume.

## Approved behavior

Version 0.4.0 introduces Lumen, Seryn's experimental architecture for model-mediated integrations:

- Optical Link stores encrypted outbound provider credentials and selects a default model without exposing the secret again;
- Seryn Link provides revocable, scoped inbound API credentials independently from interactive administrator sessions;
- the ephemeral chat supports conversation-level model selection, stable opaque session identifiers, bounded tool rounds, and read-only Seryn tools;
- Seryn's host-specific persona is direct, grounded in tool results, subtly opinionated, and separate from portable Lumen Core behavior;
- exact financial calculations remain host-owned and model output is never persisted as financial source-of-truth data;
- the repository-root `lumen/` specification records the portable architecture, security boundaries, and contracts without claiming a reusable runtime package.

The product owner manually approved Optical Link configuration, model changes within chat, response latency, tool-backed answers, the ephemeral conversation reset behavior, Seryn's persona, and the responsive browser experience against an OpenRouter free-tier connection.

## Validation limits

- OpenRouter is the only Optical Link adapter in this version; provider behavior, availability, quotas, retention, and model routing remain external concerns.
- Conversations are ephemeral and are not persisted or reused as product memory.
- Chat tools are read-only. Voice, image, chart, and video output are not implemented.
- Lumen remains experimental until another host application validates which contracts are genuinely portable.
- Physical Safari/iPhone, Unraid hardware, and external reverse-proxy behavior remain environment-specific validation.
