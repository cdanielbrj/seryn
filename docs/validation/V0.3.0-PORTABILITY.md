# Version 0.3.0 portability validation

Validation ran on November 21, 2026, on Docker Desktop for macOS arm64. Build and test runtimes ran in containers, and destructive integration coverage used temporary SQLite databases rather than the shared development volume.

## Approved behavior

Version 0.3.0 adds authenticated user-data portability through separate Export and Import destinations:

- canonical XLSX export with records, objectives, types, hierarchical categories, and payment methods in separate sheets;
- XLSX and XLSM import with exact Seryn headers, formula rejection in recognized columns, and ignored external workbook content;
- duplicate-safe merge without public database IDs;
- complete replacement of user-entered data after full-workbook validation and a separate destructive confirmation;
- transactional rollback boundaries that exclude the local user, sessions, keys, and host configuration;
- no CSV or legacy XLS contract.

The product owner manually approved export, merge import, and complete replacement in the shared local installation without detecting functional or visual problems.

## Validation limits

- User-data portability is not a host backup and does not restore authentication or deployment state.
- Physical Excel, Safari/iPhone installation, Unraid hardware, and external reverse-proxy behavior remain environment-specific validation.
