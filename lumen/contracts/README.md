# Lumen contracts

These documents define conceptual interoperability boundaries. They are not yet versioned wire schemas or generated SDK contracts.

- [Messages](messages.md): normalized conversation and model response semantics.
- [Tools](tools.md): tool definition, execution, and result rules.
- [Optical Link](optical-link.md): provider adapter responsibilities.
- [Application Link](application-link.md): inbound consumer access and capability rules.

Host public APIs may use localized field names and host-specific transport shapes. A future shared package may introduce language-neutral machine-readable schemas after multiple implementations validate them.
